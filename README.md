# Генерация новостных заголовков: TinyLlama + LoRA

Адаптация [TinyLlama 1.1B Chat](https://huggingface.co/TinyLlama/TinyLlama-1.1B-Chat-v1.0) к генерации коротких заголовков по тексту новости. Используются LoRA адаптеры для проекций внимания. Базовая модель, данные, чекпойнты и веса адаптера не входят в репозиторий.

## Данные и разделение

Источник — [news-headlines-CC-FF](https://huggingface.co/datasets/azminetoushikwasi/news-headlines-CC-FF) на Hugging Face. Скрипт выбирает:

- первые 2000 уникальных текстов из `train` для обучения;
- следующие 200 уникальных текстов из `train` для выбора чекпойнта;
- первые 100 уникальных текстов из отдельного `test`, начиная с индекса 500, только для финальной оценки. Более ранние тестовые строки использовались в предварительных экспериментах и здесь не выбираются.

Перед отбором каждого следующего набора текст приводится к нижнему регистру и нормализуются пробелы; точные повторы между тремя частями пропускаются. Близкие по смыслу или частично совпадающие статьи отдельно не выявляются.

На странице датасета нет заполненного описания лицензии. Перед распространением самих текстов или обученного адаптера необходимо отдельно выяснить условия использования. Здесь публикуется только код.

## Запуск

Потребуются интернет для первоначальной загрузки датасета и базовой модели, а также компьютер с достаточной оперативной памятью; GPU или Apple Silicon MPS ускорит обучение.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/pipeline.py train --max-steps 200 --output-dir artifacts
python src/pipeline.py evaluate --test-count 100 --output-dir artifacts
python -m unittest discover -s tests -v
```

`artifacts/` игнорируется Git: туда сохраняются чекпойнты, адаптер и метрики. Параметры `--train-count`, `--validation-count`, `--test-count`, `--max-steps` и `--seed` можно менять через командную строку. В приведённом прогоне использовано `--max-steps 200`. При накоплении градиента по четырём примерам на шаг это примерно 800 предъявлений примеров из обучающего набора из 2000 строк.

Скрипт `src/evaluate_existing.py` позволяет отдельно оценить **ранее обученный адаптер**, если он сохранён локально:

```bash
python -m src.evaluate_existing --adapter-dir /path/to/adapter --output prior_adapter_results.json
```

Для этой оценки берутся 100 записей отдельного `test`, начиная с индекса 300. Исключаются точные повторы текста после нормализации пробелов и регистра из первых 2000 обучающих, первых 205 тестовых записей, использованных в предварительных экспериментах, и уже выбранных строк. Базовая модель и адаптер оцениваются одинаково: жадная генерация до 20 токенов. Адаптер и данные не включаются в репозиторий.

Проверенный запуск ранее обученного адаптера дал следующие показатели на этих 100 строках:

| Модель | BLEU | ROUGE-1 F1 | ROUGE-L F1 |
| --- | ---: | ---: | ---: |
| Базовая TinyLlama | 0,0131 | 0,2239 | 0,1957 |
| Ранее обученный адаптер | 0,0107 | 0,2054 | 0,1799 |

Это сравнение относится только к ранее обученному адаптеру и выбранным строкам; оно **не измеряет** качество основного обучения ниже. Тот адаптер выбирался на первых 200 тестовых строках, поэтому эти результаты не относятся к полностью независимой разработке. Выбранные здесь строки не использовались для выбора его чекпойнта. Близкие дубликаты не выявлялись. Точные индексы, настройки декодирования и SHA-256 адаптера указаны в [prior_adapter_results.json](prior_adapter_results.json).

## Методика

- Шаблон диалога формируется токенизатором TinyLlama. В loss участвуют только токены заголовка; токены инструкции, статьи и padding замаскированы.
- LoRA: `r=8`, `alpha=32`, dropout `0.1`; адаптируются `q_proj`, `k_proj`, `v_proj`, `o_proj`.
- Чекпойнт выбирается по loss на валидации. Финальная генерация детерминирована (`do_sample=False`, не более 20 новых токенов).
- Тестовая оценка сравнивает базовую модель и обученный адаптер на одних строках; корпусный BLEU и средние ROUGE-1/ROUGE-L F1 записываются в `artifacts/test_metrics.json`.

## Проверенный прогон

Проверены кодирование (обучающая метка есть только у токенов заголовка), отсутствие точных повторов между частями данных и выбор отдельных строк для оценки ранее обученного адаптера. Основной LoRA-адаптер обучен 200 шагов с seed 42; лучший validation loss — 1,7174. Параметры запуска и точные ревизии базовой модели и датасета записаны в [training_info.json](training_info.json). **Полная независимая тестовая оценка основного адаптера не завершена; BLEU/ROUGE для него пока не заявляются.** Команда оценки приведена выше для последующего запуска на более быстром оборудовании. Веса адаптеров не публикуются из-за неясных условий использования датасета.
